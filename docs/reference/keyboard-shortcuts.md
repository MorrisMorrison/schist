# Keyboard shortcuts

The shortcuts in the web app. <kbd>Ctrl</kbd> on Windows and Linux, <kbd>Cmd</kbd> on macOS.

## Anywhere

| Shortcut | Action |
|---|---|
| <kbd>Ctrl/Cmd</kbd>+<kbd>K</kbd> | Quick switcher |
| <kbd>Ctrl/Cmd</kbd>+<kbd>H</kbd> | Home |
| <kbd>Ctrl/Cmd</kbd>+<kbd>,</kbd> | Settings |
| <kbd>Ctrl/Cmd</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> | New page |
| <kbd>Ctrl/Cmd</kbd>+<kbd>Alt</kbd>+<kbd>F</kbd> | New folder |
| <kbd>Ctrl/Cmd</kbd>+<kbd>B</kbd> | Show or hide the sidebar |
| <kbd>Ctrl/Cmd</kbd>+<kbd>Alt</kbd>+<kbd>T</kbd> | Switch between dark and light theme |
| <kbd>?</kbd> | List the shortcuts |
| <kbd>Esc</kbd> | Close the quick switcher or a dialog |

## On a page

| Shortcut | Action |
|---|---|
| <kbd>Ctrl/Cmd</kbd>+<kbd>E</kbd> | Switch between reading and editing |
| <kbd>Ctrl/Cmd</kbd>+<kbd>S</kbd> | Save (while editing) |
| <kbd>F11</kbd> | Focus mode (while editing) |
| <kbd>Ctrl/Cmd</kbd>+<kbd>J</kbd> | Download the page |
| <kbd>Ctrl/Cmd</kbd>+<kbd>Alt</kbd>+<kbd>D</kbd> | Delete the page |

Press <kbd>?</kbd> (outside a text field) to see this list in the app.
